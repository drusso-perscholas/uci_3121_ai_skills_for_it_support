Builder reference

Reusable Components

Hidden from learners by default. This section carries the hidden attribute, so it won't render unless you add ?library=1 to this page's URL. It's here so you can copy the raw markup for each component while building a Unit page — see the instructions near the top of the file for details.

Activity block (instructions + links + launch button)

Drop this right after any Instructional Text block. Add as many <li> links as the activity needs, or delete the list entirely if there's nothing to link beyond the launch button.

<div class="block activity-block">
  <h3><span class="tag tag-activity">Activity</span></h3>
  <p class="placeholder">Placeholder: one sentence telling the tech what to do in this activity.</p>
  <ul class="activity-links">
    <li><a href="ACTIVITY_URL_HERE">Placeholder link text</a></li>
    <li><a href="RESOURCE_URL_HERE">Placeholder link text</a></li>
  </ul>
  <a class="btn btn-primary" href="ACTIVITY_URL_HERE" target="_blank" rel="noopener" aria-label="Launch [Activity Name] in a new tab">
    <span class="btn-icon" aria-hidden="true">&#9654;</span> Launch Activity
  </a>
</div>

Generic buttons

One shared .btn class plus a variant. Pick the one that matches how important the action is.

<!-- Primary — the one main action on a screen (launch, submit, download) -->
<a class="btn btn-primary" href="URL_HERE">Primary</a>

<!-- Secondary — an alternative sitting next to a primary action -->
<a class="btn btn-secondary" href="URL_HERE">Secondary</a>

<!-- Ghost — a low-emphasis action (back, skip, cancel) -->
<a class="btn btn-ghost" href="URL_HERE">Ghost</a>

<!-- Link style — inline, text-weight action -->
<a class="btn btn-link" href="URL_HERE">Link style</a>

<!-- Add btn-small to any variant above for a compact size -->
<a class="btn btn-primary btn-small" href="URL_HERE">Small</a>

Image block

Drop this wherever a section needs a screenshot, diagram, or other image. Write real alt text describing what the image shows or conveys — screen-reader users rely on it, since they can't see the image itself. If the image is purely decorative and adds no information, use alt="" instead so screen readers skip it. Delete the <figcaption> line entirely if the image doesn't need a caption.

<figure class="image-block">
  <img src="IMAGE_URL_HERE" alt="Placeholder: describe what this image shows for screen-reader users" loading="lazy">
  <figcaption class="image-caption">Placeholder: optional one-line caption or credit.</figcaption>
</figure>

"Work Complete" section-tracking button + Lesson Contents checkbox

Two pieces that go in two different places, linked by one shared identifier. Drop the button at the end of any section a learner should be able to mark done; drop the matching contents-list item in the <ol> inside the header's Lesson Contents nav. Give both the same identifier — the button's data-section-id and the contents item's data-tracks — and that's the only edit needed on either one. Click the button below to see the checkbox next to it react; that's exactly what happens with the real pair anywhere on the page.

✓ Not complete ← this checkbox is wired to the button on the left 
<!-- 1) THE BUTTON — place at the end of the section. Change
     data-section-id to something unique for this section (its
     own id is a safe choice). -->
<div class="track-progress">
  <button type="button" class="btn-track" data-section-id="CHANGE_ME" aria-pressed="false">
    <span class="track-icon" aria-hidden="true">&#10007;</span>
    <span class="track-label">Work Complete</span>
  </button>
</div>

<!-- 2) THE CONTENTS-LIST ITEM — place inside the <ol> in the
     header's Lesson Contents nav. data-tracks must be the EXACT
     SAME value as data-section-id above — that match is what
     links this checkbox to that button. Point the href at the
     section's own id so the link still jumps there too. -->
<li>
  <a href="#CHANGE_ME">Section Title Here</a>
  <span class="toc-status" data-tracks="CHANGE_ME">
    <span class="toc-status-icon" aria-hidden="true">&#10003;</span>
    <span class="sr-only toc-status-text">Not complete</span>
  </span>
</li>
