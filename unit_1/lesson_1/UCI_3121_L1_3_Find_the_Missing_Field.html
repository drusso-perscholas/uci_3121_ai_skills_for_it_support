Find the Missing Field

Practice · not scored

Each spec below is missing exactly one field. As you read, ask yourself: if you handed this exact spec to ChatGPT right now, what would it be forced to guess?

Example 1Connect a Loaner Laptop to CorpWiFi
Audience
Tier 1 support tech, no prior context on this ticket.
Task
Document how to connect a loaner laptop to CorpWiFi.
Required steps
  1. Open Wi-Fi settings.
  2. Select CorpWiFi from the network list.
  3. Enter the passphrase.
  4. Wait for the connection to complete.
Which field is missing from this spec?
Missing field: Success state
Without a success state, the AI does not know when the article is done, so it can pad the ending or stop before ever confirming the connection actually works.
Example 2Connect a Company Phone to CorpWiFi
Audience
Tier 1 support tech, no prior context on this ticket.
Task
Document how to connect a company phone to CorpWiFi.
Success state
The phone connects and the user can reach the internet.
Which field is missing from this spec?
Missing field: Required steps
Without required steps, the AI has to invent its own sequence from scratch, so it is more likely to guess a menu label or skip a step Tier 1 actually needs.
